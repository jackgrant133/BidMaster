# BidMaster
Model Auctioneer application in which the user runs and auction where they can add items to an auction, put them up for sale, record bids from bidders, and sell items for a profit

This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

# Installation

If you are retrieving from gitlab, then you need to `npm install` first to get all dependencies.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev 
# or
pnpm dev
# or
bun dev
```
